Course Description

This course takes you from an empty Figma file to a clickable, high-fidelity prototype you can hand to a developer. You will work on a single product from start to finish, so every technique is learned in context rather than in isolation.

We cover auto layout, components and variants in depth, because they are what separate a static mockup from a design system that survives its first round of feedback. By the last lesson you will have a portfolio-ready case study and the file structure habits that make handoff painless.

Course Content

Lesson 1 — Getting started with Figma 12:40

Set up your workspace, learn the canvas shortcuts you will use every day, and create your first frames.

Lesson 2 — Frames, grids and layout 18:05

Build responsive layouts with layout grids and constraints, and understand when to reach for each.

Lesson 3 — Auto layout in depth 24:30

Nest auto layouts, control spacing and resizing, and stop fighting your designs every time the copy changes.

Lesson 4 — Components and variants 21:15

Turn repeated elements into a component library, then use variants to handle every state in one place.

Lesson 5 — Styles, tokens and theming 16:50

Define color, text and effect styles once, and switch an entire file between light and dark themes.

Lesson 6 — Prototyping and interactions 28:20

Wire up flows, smart animate between states, and record a walkthrough you can share with stakeholders.

Lesson 7 — Handoff to developers 14:05

Document your file, name layers so they survive contact with a codebase, and export assets cleanly.
